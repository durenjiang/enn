## 数据源回退链（实测，按优先级）

1. **日线 / 换手率**：baostock `query_history_k_data_plus`（字段 `date,open,high,low,close,volume,amount,turn,pctChg`）→ 代码格式 `sh.600519`，排除 bj 与 8/4/9 开头。
2. **实时快照 / 换手 / 流通市值 / PE/PB**：腾讯 `qt.gtimg.cn`（`curl --noproxy "*"` 直连，`yz.py quote`）。
3. **全市场快照**：akshare `stock_zh_a_spot()`（新浪）——**盘前 09:00–09:30 会返回全 0 占位**，此时不能用。
4. **禁用**：东方财富系接口（代理限流/断连）；`api.github.com`（MITM 拦截）；任何 web_search / 编造数字当行情。
